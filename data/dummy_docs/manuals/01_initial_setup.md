# 初期設定ガイド

本ガイドでは、ERPNavi を新規導入する際に最初に行うべきテナント設定・会社情報登録・組織階層の設定手順を説明します。初期設定は導入プロジェクトの最初の1〜2週間で完了させることを推奨します。

## テナントの作成

ERPNavi 管理コンソール（https://admin.erpnavi.example.com）にアクセスし、契約時に発行された「テナント発行コード」を入力してテナントを作成します。テナント作成時には以下の情報が必須です。

- 会社名（正式名称・法人番号）
- 本社所在地
- 利用開始予定日
- 主契約管理者のメールアドレス

テナント作成が完了すると、主契約管理者宛に初回ログイン用の招待メールが送信されます。招待メールのリンクは発行から72時間で失効するため、届いたら速やかにログインしてください。

## 会社情報の登録

初回ログイン後、「設定 > 会社情報」から以下を登録します。

1. 会計年度の開始月（4月始まり・1月始まりなど）
2. 基準通貨（日本円を基準とする場合は JPY を選択）
3. 標準タイムゾーン（国内利用の場合は Asia/Tokyo）
4. 会社ロゴ（帳票・見積書に印字されます）

会計年度の開始月は、会計モジュール設定後に変更すると仕訳データの整合性が崩れるため、初期設定完了までに必ず確定させてください。

## 組織階層の設定

「設定 > 組織構造」から部門・拠点・グループ会社の階層を登録します。ERPNavi では最大5階層まで組織を定義でき、在庫管理・会計モジュールの権限スコープはこの組織階層に紐づきます。

### 部門コードの命名規則

部門コードは英数字4〜8桁で設定します。将来の組織再編を見据え、拠点コード＋部門連番（例: TKY-001）のように命名することを推奨します。命名規則を後から変更すると、過去データとの紐付けレポートが崩れるため、初期設定時に運用ルールを固めておくことが重要です。

### 承認フローとの関係

組織階層は、購買・会計モジュールの承認ワークフロー（上長承認・部門長承認）の起点になります。組織階層の設定を誤ると、承認者が正しく割り当てられず、申請が承認待ちのまま滞留する不具合の原因になるため、設定後は必ずテスト申請で承認ルートを確認してください。

## 初期設定完了のチェックリスト

- [ ] テナント作成・主契約管理者ログイン確認
- [ ] 会計年度・基準通貨・タイムゾーンの登録
- [ ] 組織階層（部門・拠点）の登録
- [ ] テスト申請による承認ルートの確認

このチェックリストが完了したら、「02_ユーザー管理ガイド」に進み、利用者アカウントとロールの設定を行ってください。
