# ユーザー管理ガイド

利用者アカウントの発行、権限ロールの設計、シングルサインオン（SSO）連携、パスワードポリシーの設定について説明します。

## ユーザーアカウントの発行

「設定 > ユーザー管理 > 新規ユーザー」から、氏名・社員番号・所属部門・メールアドレスを入力してアカウントを発行します。CSVインポートにも対応しており、100名を超える一括登録の場合はテンプレートCSVを使った一括インポートを推奨します。

アカウント発行直後は「仮パスワード」が設定され、初回ログイン時にパスワード変更が強制されます。招待メールが届かない場合は、迷惑メールフォルダの確認と、送信元ドメイン（notify.erpnavi.example.com）の許可リスト登録を案内してください。

## 権限ロールの設計

ERPNavi の権限は「ロール」単位で管理し、1ユーザーに複数ロールを割り当てられます。標準ロールは以下の4種類です。

| ロール名 | 権限範囲 |
|---|---|
| 一般利用者 | 自身の申請・照会のみ |
| 部門承認者 | 所属部門の申請承認 |
| モジュール管理者 | 特定モジュール（会計・在庫等）の設定変更 |
| システム管理者 | 全モジュールの設定・ユーザー管理 |

標準ロールでは要件を満たせない場合、「カスタムロール」を作成できます。カスタムロール作成時は、権限を必要最小限に絞る最小権限の原則に従うことを推奨します。特にモジュール管理者・システム管理者ロールは、退職者・異動者のアカウントに残存しやすいため、四半期ごとの棚卸しを行ってください。

## シングルサインオン（SSO）連携

Microsoft Entra ID（旧 Azure AD）とのSAML連携に対応しています。連携設定は「設定 > セキュリティ > SSO設定」から、IdP発行のメタデータXMLをアップロードすることで完了します。

SSO有効化後は、ERPNavi独自パスワードでのログインは無効化され、原則としてIdP側の認証ポリシー（多要素認証等）に従います。ただし、緊急時アクセス用に「緊急ログインアカウント」を1つ以上残しておくことを強く推奨します。IdP側で障害が発生した場合、緊急ログインアカウントがないとシステムに一切アクセスできなくなります。

## パスワードポリシー

SSOを利用しない場合のパスワードポリシーは「設定 > セキュリティ > パスワードポリシー」で設定します。デフォルトは以下の通りです。

- 最小文字数: 10文字
- 有効期限: 90日
- 過去5世代のパスワード再利用禁止
- 5回連続ログイン失敗でアカウントロック（ロック解除はシステム管理者が実施）

金融・会計データを扱う関係上、パスワードポリシーを緩和する変更は監査ログに記録され、変更理由の入力が必須となります。
